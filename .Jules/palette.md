## 2025-05-18 - Gradio Medical AI Interface Polish & Accessibility
**Learning:** In medical diagnostic interfaces with lengthy disclaimers, placing disclaimers directly in the main view pushes primary upload and interactive controls below the fold. Wrapping secondary disclaimer text in a collapsible `gr.Accordion(open=False)` declutters the interface while keeping terms accessible. Furthermore, Gradio `scale` in columns should use integers (`scale=1`, `scale=2`) rather than floats (`scale=0.5`) in Gradio 3.24.1, and explicit labels on `gr.Image` provide vital screen reader context.
**Action:** When working with Gradio interfaces that display long regulatory or disclaimer text, wrap them in collapsible accordions, use secondary variants for reset actions, and ensure all input components have clear labels and parameter helper descriptions (`info`).
