## 2025-02-15 - Integer Column Scaling and Descriptive Slider Help Texts in Gradio 3.24.1
**Learning:** Gradio 3.24.1 supports custom column layouts, but float-based scaling (like `scale=0.5`) can cause unpredictable or broken UI column widths depending on the browser window size. Converting them to integer scaling factors (e.g., `scale=1` for the left side and `scale=2` for the right side) preserves the exact 1:2 layout ratio reliably. Additionally, when exposing machine learning parameters (such as Temperature and Beam Search Numbers) in clinical or medical AI assistants, using the `info` attribute to explain how those parameters influence output randomness, quality, and latency significantly reduces cognitive load and improves accessibility.
**Action:** Always use integer values for Gradio column scaling to avoid viewport rendering bugs. Ensure all model parameter sliders include a concise `info` text detailing their practical impact on user queries.
